# LUBB — لُبّ | الإصدار 1.2.0

تطبيق إنتاجية شخصي باللغة العربية واتجاه RTL، يعمل محليًا مع دعم PWA.

## الوظائف الحالية
- لوحة رئيسية فيها الساعة الحية، التاريخ الميلادي/الهجري، تقدم اليوم، وملخص المهام والملاحظات.
- إدارة المهام: إضافة وتعديل وحذف، حالات (جديد/قيد التنفيذ/مكتمل)، أولويات، بحث وتصفية.
- إدارة الملاحظات: إنشاء وتعديل وحذف، بحث في العنوان والنص، وربط بتاريخ.
- تقويم شهري يبيّن الأيام ذات المهام والملاحظات، مع عرض عناصر اليوم المختار.
- قاعدة يومية تجمع المهام والملاحظات، وإحصائيات محسوبة من بيانات المستخدم.
- مظهر فاتح/داكن/تلقائي، تنسيق الساعة 12/24، وإظهار الثواني والتاريخ الهجري.
- نسخ احتياطي JSON واستعادة مع تحقق وتأكيد، ومسح بيانات بتأكيدين.
- شعار SVG مستقل وأيقونات PNG متعددة الأحجام؛ تستخدم الواجهة PNG مع احتياط SVG لزيادة التوافق.
- Service Worker للتخزين المؤقت وإتاحة العمل دون اتصال بعد الزيارة الأولى عبر localhost/HTTPS.

## التشغيل المحلي
1. فك ضغط المشروع.
2. افتح الطرفية داخل مجلد `LUBB`.
3. شغّل `python -m http.server 8080`.
4. افتح `http://localhost:8080`.

لا تفتح `index.html` مباشرة عبر `file://` إذا أردت اختبار PWA أو Service Worker؛ استخدم localhost أو HTTPS.

## البيانات والخصوصية
تُخزّن البيانات في LocalStorage على المتصفح والجهاز الحالي. لا توجد مزامنة سحابية. امسح بيانات المتصفح أو استخدم تصدير النسخة الاحتياطية قبل تغيير الجهاز. ملفات النسخ الاحتياطي تحتوي بياناتك الشخصية، فاحتفظ بها في مكان آمن.

## التثبيت
من متصفح يدعم PWA افتح التطبيق عبر HTTPS أو localhost ثم اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية» بحسب المتصفح.

## الاختبارات المنفذة
- فحص صياغة JavaScript باستخدام `node --check app.js`.
- التحقق من صلاحية JSON في `manifest.webmanifest`.
- فحص وجود أصول الشعار والأيقونات وملفات PWA.

## حدود التحقق
لا توجد مزامنة سحابية أو إشعارات/تذكيرات خلفية. يجب إجراء اختبار على المتصفح والجهاز المستهدف قبل الاعتماد الإنتاجي، بما يشمل تثبيت PWA، دورة تحديث Service Worker، والاستيراد/التصدير على الجهاز النهائي.
