# LUBB — لُبّ

تطبيق عربي شخصي لإدارة المهام والملاحظات والوقت، مبني بهندسة بسيطة باستخدام HTML وCSS وJavaScript دون مكتبات خارجية.

## التشغيل
- **أفضل طريقة:** شغّل خادم ملفات ثابتة من مجلد المشروع، مثل `python -m http.server 8080`، ثم افتح `http://localhost:8080`.
- لا يُنصح بفتح `index.html` مباشرة إذا كنت تريد ميزات PWA؛ متصفحات الويب تتطلب HTTPS أو localhost لتسجيل Service Worker.
- على الهاتف، افتح عنوان التطبيق من المتصفح واختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق» عند ظهور الخيار.

## الوظائف
- ساعة حية مع 12/24 ساعة، خيار الثواني، تاريخ ميلادي وهجري (يعتمد التاريخ الهجري على دعم `Intl` في المتصفح)، ونسبة مرور اليوم.
- مهام قابلة للإضافة والتعديل والحذف، وحالات جديد/قيد التنفيذ/مكتمل، وأولويات وتصفية وبحث.
- ملاحظات بعناوين ونصوص وتاريخ، بحث وتعديل وحذف.
- تقويم شهري تفاعلي يعرض المهام والملاحظات المرتبطة بالأيام.
- قاعدة رئيسية تجمع العناصر حسب التاريخ.
- إحصائيات مشتقة من البيانات الفعلية.
- إعدادات محفوظة، مظهر فاتح/داكن/تلقائي، وتصدير/استعادة JSON مع تحقق وتأكيد.
- PWA مع Manifest وService Worker وتخزين مؤقت للملفات الأساسية.
- كل البيانات محلية في `localStorage` على هذا الجهاز؛ لا يوجد خادم أو حساب أو مزامنة سحابية.

## التخزين والنسخ الاحتياطي
يُحفظ محتوى التطبيق في المفتاح `lubb-data` داخل `localStorage`. صدّر نسخة JSON من شاشة الإعدادات بشكل دوري؛ مسح بيانات المتصفح قد يحذف البيانات المحلية. لا تشارك النسخ الاحتياطية لأنها تحتوي على بياناتك الشخصية.

## الملفات
- `index.html` — بنية التطبيق.
- `styles.css` — الهوية البصرية والتجاوب.
- `app.js` — منطق التطبيق والتخزين والواجهات.
- `manifest.webmanifest` — تعريف PWA.
- `sw.js` — التخزين المؤقت وتحديث ملفات التطبيق.
- `assets/` — شعار SVG وأيقونات التطبيق.

## الاختبارات وحدود التحقق
تم إجراء فحص بنيوي لوجود ملفات المشروع وصحة JSON للـ Manifest، وإجراء فحص نحوي لملف JavaScript عند توفر Node.js في بيئة البناء. لم يُنفّذ اختبار متصفح آلي شامل في بيئة حقيقية، لذلك يجب تجربة التدفقات الأساسية بعد فك الضغط. لم تُنفّذ مزامنة سحابية أو تنبيهات أو تذكيرات في الخلفية. يعمل Service Worker عبر localhost أو HTTPS فقط، كما أن سياسة التخزين قد تختلف بين المتصفحات.
